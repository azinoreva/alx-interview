# Prime Game

## Description
This project is a solution to the **Prime Game** problem, where Maria and Ben play a game involving prime numbers. Given a set of consecutive integers starting from 1 up to and including `n`, they take turns choosing a prime number from the set and removing that number and its multiples. The player who cannot make a move loses the game.

Maria always goes first, and both players play optimally. The goal is to determine the overall winner after playing `x` rounds, with `n` possibly varying for each round.
